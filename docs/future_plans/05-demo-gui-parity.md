# Примитивы конфигурации должны собираться в GUI

Найдено 2026-11-03 при завершении M2.2, по просьбе пользователя: администратор должен уметь
собрать в GUI каждый **примитив конфигурации**, из которых состоит мир, — карту, план, тип
диаграммы, регион, диаграмму, точку, иконку, размещение камеры, права, уровень, видеостену.
Демо — проверка этого свойства, а не отдельная возможность: `DemoSeeder` пишет мир только через
обычные сервисы, поэтому всё, что он умеет, обязано иметь путь в GUI. Если примитив доступен
только из кода, продукт умеет его выражать только кодом.

Это не про замену сидера: демо остаётся переустанавливаемым кодом. Это про полноту GUI.

Аудит примитивов сделан (каждый имеет путь в GUI: `SpaceForm`/`SpaceEditor`,
`MapDiagramTypesDialog`, `DiagramElementEditor`, `ObjectPropsEditor`, Admin → Maps → Devices,
`ObjectRights`, Admin → Monitors, Admin → Cameras → Devices, Admin → Event routing, Admin →
Deployment). Осталось то, что ниже.

## Что осталось

- **Playwright-прогон «собрать мир только через GUI» не сделан.** Нужен одноразовый прогон,
  который проходит примитивы (карта → план → тип → диаграммы → камеры → стена → вкладка Devices →
  Event routing), а затем сверяется с ожиданиями `tests/demo/check_demo.py`. Состояния и значения
  в нём пропускаются: это данные времени выполнения, а не конфигурация (см. ниже). Браться за
  него — когда UI карты и устройств перестанет меняться каждый майлстоун.
- **Свободные фигуры на планах.** На диаграмму можно положить текст, линию, зону и иконку
  (`geo_objects` с `canvas_id` диаграммы, M2.2). На плане есть только точка, линия и многоугольник
  (`createFigure` в `SpaceEditor`): текста, иконки и картинки как свободных фигур нет. Решение
  «план и диаграмма — две сущности, общими остаются возможности, а не таблицы» записано в
  [`../plans/square-merge/m2.2-demo-configuration.md`](../plans/square-merge/m2.2-demo-configuration.md);
  возможностями оно и означает текст/иконку/картинку на плане.
- **Демо-подписку можно удалить в Event routing**, и до переустановки мира демо-реакция пропадёт.
  Пометки «принадлежит демо» в UI нет; повторная установка возвращает правило (фиксированный id).
  Стоит либо пометить, либо запретить удаление.
- **Новая диаграмма ставится в центр вида, а не по клику.** Не блокер (точку можно перетащить),
  но для сборки мира вручную неудобно; можно добавить режим «поставить диаграмму кликом».

## Что примитивом не является

1. **Состояния (`UpdateStates`).** Состояние пишет владелец — VmsFs (обрыв источника), retention,
   ONVIF. Демо больше не пишет синтетических состояний: единственная его строка — `CONNECTED` на
   порту, чтобы перезаписать `DISCONNECTED` прежних версий мира. Вручную состояние не ставится и
   не нужно — пользователь получит настоящую тревогу, отключив камеру.
2. **Значения (`temp`/`humidity`).** `DemoValueFeeder` — заглушка до M2.3; в GUI редактора
   значений нет и не планируется: значения приходят от устройств. После M2.3 их место займут
   реальные параметры ONVIF (геолокация, реле).

Это данные времени выполнения, а не конфигурация: их отсутствие в GUI — не пробел.
