# Будущие планы

Найденное, что нужно сделать, но не следующим шагом: один файл — одна тема, записанная тогда,
когда её нашли, с тем, что было установлено, и с тем, что осталось. Это не обязательства и не
бэклог в порядке приоритета: файлы сохраняют знание между сессиями.

Когда работа по теме начинается, план переезжает в саму работу (файл плана, PR), а файл здесь
удаляется или сокращается до того, что осталось. Закрытые планы по решению пользователя
сохраняются в [legacy/](legacy/) — это история решённых тем, а не список дел; в таблице ниже их
нет.

**Номер в имени файла — порядок по предполагаемой простоте, а не по важности:** `01` — то, с чего
дешевле всего начать; `17` — то, что требует нескольких машин, железа или внешних решений. Порядок
приблизительный: темы пересекаются, и зависимости названы в самих файлах. При пересмотре порядка
файлы перенумеровываются, а ссылки на них правятся — искать по имени, а не по номеру.
